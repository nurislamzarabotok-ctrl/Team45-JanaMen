JanaМен 1.4 iPhone PWA — отчёт проверки

Автоматические тесты: 151 PASS, внешние запросы запрещены runner.
Браузер: Chromium с профилем iPhone 13 (touch/DPR3); НЕ Safari/WebKit.
54 проверки: 9 разделов × 6 размеров (390×844, 844×390, 375×812,
428×926, 768×1024, 1440×1000). Горизонтального переполнения нет,
JS-ошибок в прогоне нет. Светлая/тёмная темы осмотрены.

7 основных сценариев PASS:
1. Заявка создана мобильным сотрудником.
2. Согласование на десктопе руководителем отображается без F5 на мобильном.
3. Завершение HR на десктопе отображается на мобильном.
4. Общая задача обновляется на мобильном после изменения статуса на десктопе.
5. Polling не уничтожает редактируемую заметку; форма доступна при коротком окне.
6. Gemini: вопрос/уточнение через ЛОКАЛЬНЫЙ native Google-shaped HTTP stub.
7. SW: public offline fallback, API не в Cache Storage, восстановление сессии онлайн.

4 дополнительных сценария PASS:
- Полное HR-меню прокручивается; выход достижим; Escape снимает блокировку.
- При simulated document.hidden polling приостановлен; на возврате стартует сразу.
- API работает без AbortSignal.timeout (AbortController fallback).
- Landscape: форма прокручивается до отправки.

Публичный кеш: только offline.html/css, manifest и иконки/логотип.
Данные сотрудников, чаты и API не кешируются для офлайн-просмотра.
Непроверенные среды: физический iPhone 13/iOS Safari/реальная клавиатура,
установка из Safari, Windows bat, внешний HTTPS tunnel, Docker build.
Нет live-запросов Google в тестах. Не подменять локальный stub утверждением,
что реальная модель или оплаченная квота проверены.

Артефакты: IPHONE_BROWSER_RESULT.json, IPHONE_ADDITIONAL_RESULT.json.
QA-скриншоты и база с тестовыми аккаунтами в архив не включены.
