JanaМен 1.2 — обычный ИИ-чат · команда 45

Платформа и её функции сохранены. В AI Jana по умолчанию теперь обычный текстовый диалог с моделью, а не обязательный ответ с точными цитатами.

ЗАПУСК НОВОЙ КОПИИ
1. Распакуйте архив. Откройте папку JanaMen с server.py.
2. Откройте AI_KEY.txt. Замените строку-заглушку одним НОВЫМ ключом AnyModel, сохраните.
   Не отправляйте ключ в чат. Ранее опубликованный ключ следует отозвать.
3. В PowerShell этой папки: py -3 server.py --port 8016 --no-browser
4. Откройте http://localhost:8016, войдите, откройте AI Jana и создайте НОВЫЙ диалог.
   Демо-данные входа создаются при первом запуске в data/DEMO-ACCOUNTS.txt.
5. Для отдельной проверки настройки: py -3 scripts/check_ai.py --local
   Для одного реального платного запроса API: py -3 scripts/check_ai.py

Модель по умолчанию am/gpt-oss-20b уже указана. Менять её для запуска не нужно.
AnyModel: https://anymodel.org/v1/chat/completions. По умолчанию используется curl.exe с SSE.
Если API не принимает ключ/модель или нет сети, появится явная ошибка. Текст базы вместо ответа ИИ не подставляется.

ОБНОВЛЕНИЕ С СОХРАНЕНИЕМ ДАННЫХ 1.1
1. Остановите старый сервер Ctrl+C. Сделайте резервную копию всей старой папки.
2. Распакуйте 1.2 ОТДЕЛЬНО. Из остановленной 1.1 скопируйте папку data в новую JanaMen.
3. Перенесите AI_KEY.txt с новым действующим ключом. Старую .env переносить не обязательно.
   Если настройки сервера нужны, переносите их выборочно: JANA_AI_CHAT_MODE=chat;
   JANA_AI_DAILY_LIMIT=0. Не переносите старый лимит 40 или режим grounded.
4. Запускайте сервер именно из новой папки. Откройте порт 8016 и новый диалог.
   Если порт занят, остановите его владельца или выберите другой порт.
5. Если интерфейс остался старым, нажмите Ctrl+F5.

ЧТО УБРАНО В ОБЫЧНОМ РЕЖИМЕ
- готовое приветствие вместо обращения к модели;
- отказ только потому, что не найдена статья или ключевое слово;
- запрет общих вопросов и грубый список запрещённых слов;
- обязательный JSON, точные цитаты и отбрасывание текста без цитаты;
- подстановка готовых выдержек при сбое API;
- дневной лимит платформы по умолчанию (0 = без дневного лимита).

ЧТО ОСТАЛОСЬ
- права доступа и защита ключа; кадровые записи не добавляются к запросу модели;
- явные запросы «Мои задачи / Мои курсы / Мой профиль / Мои заявки» обрабатываются локально;
- 8 сообщений в минуту на аккаунт, 2 одновременных запроса, тайм-аут и защита дублей;
- модель не получает право изменять базу, подписывать документы или принимать решения HR.

Модель получает до 6 последних допустимых пар вопрос/ответ ТЕКУЩЕГО диалога и до 22000 символов доступных роли инструкций. Локальные ответы по аккаунту и ответы с отозванным контекстом не передаются в историю модели. Инструкции — контекст, а не подтверждение каждого утверждения. Ответы могут ошибаться.
Не вводите в сообщения пароли, ключи и персональные данные. Отсутствие дневного лимита может увеличить расходы: тарификация и ограничения провайдера остаются.
