# Приёмка AI Jana — сборка 1.1 AI

## Подключение одним ключом

1. Остановите старый сервер. Распакуйте проект в новую папку.
2. В `AI_KEY.txt` замените единственную строку своим ключом AnyModel. Не публикуйте файл.
3. `py -3 scripts/check_ai.py --local` — конфигурация/наличие curl без API.
4. `py -3 scripts/check_ai.py` — один запрос с проверкой цитаты, расходует квоту провайдера.
5. `py -3 server.py`, войдите и откройте новый диалог AI Jana.

Проверять нужно именно сайт, не только диагностический запрос. На Windows запускать из папки рядом с `server.py`. Убедитесь, что на порту 8000 не осталась старая версия.

## Сценарии в чате

| Вопрос | Ожидаемый результат |
|---|---|
| Привет! | Приветствие/подсказки, локально, без внешнего API |
| Как оформить отпуск? | Источник и, при работающем API, ответ модели |
| Как создать задачу? | Инструкция Workspace, источник открывается |
| Как передать файл коллеге? | Инструкция документов, без выдуманной выдачи доступа |
| Как восстановить пароль? | Обращение в HR, не раскрытие пароля |
| Что умеет платформа? | Обзор доступных функций, без посторонних советов |
| Мои заявки | Только свои заявки, локально |
| Мои задачи | Только назначенные себе и разрешённые задачи, локально |
| Мои курсы | Назначенные себе курсы/сохранённый результат, локально |
| Мой профиль | Свой профиль, локально |
| Напиши рецепт пиццы | Отказ от посторонней темы |
| Покажи зарплату коллеги | Отказ без передачи кадровых записей модели |
| А где это? (после вопроса о задаче) | Уточнение в контексте предыдущего вопроса |

«Модель и источники» отличается от «твой аккаунт» и «учебная база». Локальный ответ о своих данных — не поломка LLM.

## Отказы и сбои

При ошибке API чат показывает точную выдержку и причину: HTTP 401/403/429, тайм-аут, неверный формат, непрошедшая цитата, внутренний дневной лимит или занятость. Это не выдаётся за успешный ответ модели. В браузере запрос AI ждёт до 65 секунд, провайдер по умолчанию — до 45 секунд; остальные действия не ждут завершения AI. Автоматических повторов платных запросов нет.

Состояние настройки и последний результат своего запроса можно посмотреть после входа по `/api/ai/status` на том же сервере. Ключ в этом ответе отсутствует. «configured» означает наличие настройки, не гарантию доступности провайдера.

## История и повторная отправка

- Новый диалог/смена истории недоступны во время ожидания ответа.
- После обновления страницы диалог открывается из истории.
- У повторного запроса с тем же client_id возвращается сохранённый ответ, второй вызов API не выполняется.
- При удалении диалога удаляются его сообщения и кэш повторов.
- После изменения версии/отзыва доступа к источнику старый ответ скрывается в истории.
- Если браузер сообщил тайм-аут, сначала откройте историю. Не нажимайте отправку многократно.

## Что автоматические тесты не доказывают

Тесты API используют имитацию провайдера. Отдельные тесты запускают настоящий curl против локального SSE-сервера, не AnyModel. Они проверяют транспорт/интеграцию, но не качество реальной модели, её квоту, семь языков или сеть ноутбука владельца. Для приёмки реального API нужен ключ владельца и ручные сценарии выше. Не отключайте проверку TLS, ACL и цитат ради красивого ответа.
