# Отчёт сборки 1.1 AI

## Автоматические проверки

**86 тестов, OK**, Linux/Python 3.13, чистые временные SQLite-базы.

- Регрессионные тесты HR/Workspace/файлов/обращений/Academy/ACL.
- Конфигурация одним ключом, BOM, перечитывание ключа, заглушка, приоритет настроек, отсутствие секретов в публичном статусе.
- AnyModel curl/SSE и Groq urllib/JSON, потоковые Unicode-фрагменты, обычный JSON, обрыв, ошибка в потоке, переполнение и отделение reasoning от ответа.
- Настоящий curl против **локального тестового HTTP/SSE-сервера**, без запросов в AnyModel.
- Полный `/api/assistant`: темы модулей, локальные приватные ответы, история, контекст уточнения, идемпотентность, источник после изменения версии, объяснение HTTP 403, работа других модулей во время ожидания AI.
- Закрытый доступ к `AI_KEY.txt`, `.env`, Python-файлам через HTTP; отсутствие ключа в статусе/аргументах curl.

## Браузерная проверка

Chromium, реальная страница → API платформы → настоящий процесс curl → **локальная имитация SSE** → проверка цитат → отображение/история/источник: PASS. Проверены приветствие, свои курсы, задача, уточнение, посторонний вопрос, HTTP 503 и вопрос о файлах. Ошибок JavaScript не было. Светлая/тёмная тема, desktop 1440 и mobile 390 просмотрены; ширины 360/390/412/768/1440 — без горизонтального переполнения страницы. Длинная база знаний прокручивается внутри карточки, не растягивая чат.

Повторный сквозной прогон в трёх независимых контекстах: общая задача, обращение, файл/текстовый поиск, адаптация, сотрудник → руководитель → HR → сотрудник, обновление без F5: PASS, ошибок JavaScript нет.

## Границы подтверждения

Реальный AnyModel с ключом владельца в этой среде **не вызывался**. У владельца ранее прошёл отдельный live-запрос с цитатой; это не заменяет приёмку новой сборки в его браузере. Не проверены реальные телефоны, Safari/WebKit, запуск этой сборки на Windows, публичный HTTPS, Docker build, нагрузка/независимый аудит и профессиональное качество семи языков. Никаких обещаний «без сбоев при любом ключе/провайдере» этот отчёт не даёт.

Повтор: `python -m unittest discover -s tests -v`.
Реальное подключение: `python scripts/check_ai.py` (один внешний запрос).

Дополнительно чистая распакованная копия проверена через браузер с единственным `AI_KEY.txt` (фиктивный локальный ключ, без `.env`). Истинный API не вызывался. Тестовый запуск с настроенным ключом также прошёл с запретом внешних HTTP/curl-запросов: `python scripts/run_tests.py`.
