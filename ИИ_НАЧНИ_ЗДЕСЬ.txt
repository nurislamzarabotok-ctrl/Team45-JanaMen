JanaМен 1.4 iPhone · Gemini · команда 45 · Digital HR

Это ПОЛНАЯ сборка платформы. Внешний вид и функции сохранены.
Gemini подключён напрямую к Google REST API generateContent, без AnyModel.
Python 3.10+, стандартная библиотека; SDK, pip и curl для Gemini не требуются.

ПЕРВЫЙ ЗАПУСК
1. Остановите прежний сервер Ctrl+C и сохраните резервную копию старой папки.
2. Распакуйте этот архив В НОВУЮ папку. Откройте JanaMen с server.py.
3. Откройте GEMINI_KEY.txt. Удалите строку-заглушку и вставьте ОДИН ключ из Google AI Studio.
   Без кавычек, без «API key:», без curl-кода. Сохраните файл. Он не должен называться GEMINI_KEY.txt.txt.
   Не публикуйте ключ и не присылайте его в чат.
   Альтернатива: ПОДКЛЮЧИТЬ_ИИ.bat (ключ вводится скрыто в локальном терминале).
4. Откройте PowerShell в этой папке:
   py -3 scripts/check_ai.py --local
   Это только проверка чтения файла, НЕ запрос к Google.
5. Проверка Google напрямую:
   py -3 scripts/check_ai.py
   Либо CHECK_GEMINI.bat. Сначала запрашивается список доступных моделей (при auto),
   затем ОДНА генерация; она может расходовать токены. Ключ и текст ответа не печатаются.
   Успех: «OK: получен текстовый ответ API» и точное имя модели.
6. Запустите START_IPHONE_SERVER.bat либо:
   py -3 server.py --port 8018 --no-browser
   Откройте http://localhost:8018. Войдите, перейдите в AI Jana, создайте НОВЫЙ диалог.
   Демо-данные входа при первом запуске: data/DEMO-ACCOUNTS.txt (не публикуйте).
7. Проверьте «Привет», «Как изменить цвет фона?», затем уточнение «А где эта кнопка?».
   У ответа должна быть метка «Jana · Gemini». Внизу: «Сборка 1.4 iPhone · Gemini», после запроса — точная модель.

КАК ПЕРЕНЕСТИ ПРЕЖНИЕ ДАННЫЕ
- Остановите сервер. Из старой JanaMen скопируйте папку data в НОВУЮ JanaMen.
- НЕ переносите старые .env и AI_KEY.txt: они относятся к старой настройке.
- В GEMINI_KEY.txt вставьте ключ Google. Перед запуском проверьте нужную папку в PowerShell.
- Если использовали JANA_DB в старой .env, перенесите базу и связанные файлы правильно либо задайте путь отдельно.
- Порт 8018 выбран, чтобы не попасть на старую копию на 8000/8016. При занятом порте остановите его владельца или укажите другой.
- При старом интерфейсе нажмите Ctrl+F5. Обязательно создайте новый диалог: старые сообщения не переписываются.

ВЫБОР МОДЕЛИ
Вручную выбирать модель обычно не нужно: JANA_GEMINI_MODEL=auto.
Сервер получает models от Google и выбирает текстовую модель с generateContent. Предпочтение — доступной Flash/Flash-Lite.
Точное имя показывается в диагностике и под чатом. Список кешируется в памяти на 10 минут отдельно для каждого ключа.
Наличие модели в списке НЕ гарантирует квоту, доступ к генерации или бесплатность.
Другие модели после ошибки генерации автоматически не перебираются; повторных платных генераций нет.
Если нужна конкретная модель: создайте .env со строкой JANA_GEMINI_MODEL=gemini-ИМЯ_ДОСТУПНОЙ_МОДЕЛИ.
При явном имени запрос списка не выполняется. Имя берите из AI Studio/актуального списка Google.

ЕСЛИ НЕ РАБОТАЕТ
- Ключ настроен: нет — проверьте GEMINI_KEY.txt, имя без .txt.txt и ту ли папку запускаете.
- gemini_key_invalid / HTTP 400 — проверьте ключ и параметры модели.
- gemini_key_restricted / HTTP 403 — разрешения ключа, доступ Gemini API, ограничения проекта/региона.
- HTTP 404 — проверьте конкретное имя модели, если задавали его вручную.
- HTTP 429 — квота/частота/биллинг Google. Наличие ключа само по себе не даёт доступную квоту.
- HTTP 503 — временная недоступность Google.
- timeout / network — сеть, TLS, прокси или доступ к generativelanguage.googleapis.com.
- gemini_blocked — собственные правила Google остановили ответ. Они этой программой не отключаются.
- gemini_no_model — Google не вернул подходящей текстовой модели.
Если прямая проверка OK, но сайт не работает: проверьте порт, папку и сборку внизу AI Jana.
Для обращения за помощью достаточно вывода check_ai.py и текста ошибки чата; ключ не присылайте.

ЛОГИКА ЧАТА
- Обычный текстовый диалог. Приветствия и вопросы без статьи отправляются модели.
- До 6 последних допустимых пар текущего диалога + доступные роли инструкции передаются Google.
- Инструкции — справочный контекст, не обязательные цитаты и не доказательство каждого утверждения.
- Собственные заявки/курсы/задачи/профиль по явным запросам проверяются локально; кадровые записи в API не добавляются.
- Не вводите в сообщения ключи, пароли и персональные данные: написанный вами текст будет передан Google.
- При сбое показана ошибка. Готовая выдержка вместо ответа ИИ не подставляется.
- Права доступа, проверка актуальности источников, защита дублей, 8 сообщений в минуту и 2 параллельных запроса сохранены.
- Дневного лимита платформы по умолчанию нет (0). Ограничения и тарификация Google остаются.
- ИИ не изменяет базу, не подписывает документы, не выполняет кадровые решения. Его ответы могут ошибаться.

ТЕХНИЧЕСКИ
GET https://generativelanguage.googleapis.com/v1beta/models
POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent
Ключ идёт только в заголовке x-goog-api-key, не в URL/браузер/публичный статус.
TLS проверяется; перенаправления и автоматические повторы не выполняются.
Публичный /api/ai/status доступен после входа и показывает build, настройку, resolved_model, last_result без ключа.
